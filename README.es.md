## ⭐ Proyecto destacado — MineOps

Plataforma de gestión de operaciones mineras que cubre la cadena completa: mina, planta, inventario,
mantenimiento, seguridad y planificación sobre una única base de datos multi-empresa. Nació de
generalizar un sistema que ya operaba en una cantera, y se completó con las prácticas estándar de la
industria que ese sistema no cubría: control de leyes, reservas, confiabilidad de activos y
reconciliación mina-planta.

Cuatro decisiones lo sostienen:

1. **El stock es un libro mayor, no un saldo.** Una sola tabla de movimientos con signo y trazabilidad
   al documento de origen. No se edita ni se borra un asiento: se contra-asienta.
2. **Las líneas de producción se definen en datos.** Agregar un producto o una medición es
   configuración, no una migración.
3. **La planificación baja por recetas recursivas**, con rendimiento del proceso y merma del componente
   como correcciones separadas.
4. **Multi-empresa desde la primera tabla.** Dar de alta una minera nueva no toca una línea de código.

Doce módulos de dominio y doce motores de cálculo mantenidos aparte de ellos. Python · Flask ·
SQLAlchemy · PostgreSQL.

> **[🌐 Recorrido completo con capturas](https://reinack.github.io/mineops-demo/)** — el código fuente
> es privado; la vitrina corre sobre un dataset de demostración enteramente ficticio.
