## ⭐ Featured — MineOps

A mining operations platform covering the full chain: pit, plant, inventory, maintenance, safety and
planning, on a single multi-tenant database. It was born by generalizing a system already running at a
working quarry, then completed with the industry practices that system did not cover — grade control,
reserves, asset reliability and mine-to-mill reconciliation.

Four decisions hold it together:

1. **Stock is a ledger, not a balance.** One movements table with signed entries and traceability to the
   source document. Entries are never edited or deleted — they are reversed.
2. **Production lines are defined in data.** Adding a product or a measurement is configuration, not a
   migration.
3. **Planning resolves through recursive recipes**, with process yield and component loss as separate
   corrections.
4. **Multi-tenant from the very first table.** Onboarding a new mining company touches no code.

Twelve domain modules and twelve calculation engines kept separate from them. Python · Flask ·
SQLAlchemy · PostgreSQL.

> **[🌐 Full walkthrough with screenshots](https://reinack.github.io/mineops-demo/)** — the source is
> private; the showcase runs on an entirely fictional demo dataset.
